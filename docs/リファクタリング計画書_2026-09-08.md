## 1. 現状理解（実行者への文脈共有）

### 1.1 アプリの概要

崩壊：スターレイル（HSR）・原神・ゼンレスゾーンゼロ（ZZZ）の公開 UID からキャラクターのビルドを診断し、全248キャラクターの個別ビルド・凸（星魂／命ノ星座／心象映画）・推奨PT（パーティ）を表示する Web サイト。フロントエンドは React 19 + Vite を GitHub Pages に静的配信し、API は Express + tRPC を Railway で `API_ONLY=true` で常駐させる。MySQL（Drizzle）には users / translation_feedback / lookup_analytics_events の3表しかなく、**キャラクターデータの正本はすべて `server/` 配下の TypeScript データファイル**である。

処理の流れ:

1. `client/src/pages/Home.tsx` が `build.lookup`（game, uid）を呼ぶ → `server/routers.ts` が `lookupGameBuild()`（`server/gameProviders.ts`）を実行。HSR は MiHoMo（6秒予算）→失敗時 Enka（`server/enkaFallback.ts`）、原神・ZZZ は Enka を取得し、`normalize*Payload` がキャラクターごとに「ガイド（`guideFor` / `genshinGuide` / `zzzGuide`）・比較表・優先強化・装備提案・推奨PT（`partyRecommendationsFor`）・凸（`constellationProfileFor`、`game:sourceId` キー）」を組み立てる。結果は UID 単位の TTL キャッシュ（`UidResponseCache`）に保存する。
2. 最後に `routers.ts` が `applyBatch15CuratedOverrides()` を通し、第15バッチ20名だけ API 境界でガイド・PT・凸を上書きする（第15バッチだけが基底データに畳み込まれていない）。
3. `client/src/pages/CharacterCatalog.tsx`（図鑑・UID不要）は `build.referenceCatalog` / `build.reference` を呼ぶ → `server/characterReference.ts` がカタログ名から同じガイド・PT・凸を解決する。凸だけはカタログ名を `CATALOG_NAME_TO_SOURCE_ID`（手書き48件）で source ID へ解決してから引く。
4. `client/src/pages/GuideHistory.tsx`（/updates）は `build.guideHistory` を呼ぶ → `guideUpdateHistory()`（サイト全体イベント＋248名の個別イベント＋台帳集計）に `applyBatch15History()` を重ねて返す。
5. データ更新は「バッチ」単位で行われてきた（第1〜17。全248名精査済み）。1バッチの登録先は `characterUpdateLedger.ts`（台帳）・`characterGuideMetadata.ts`（日付・出典）・`guideUpdateHistory.ts`（履歴イベント）・各データファイル・`docs/batch-N-research-notes.md` に分散している。

### 1.3 実行者が壊してはいけない不変条件

1. **公開 API のレスポンス形とデータ値**。`build.lookup` / `build.reference` / `build.referenceCatalog` / `build.guideHistory` が返す JSON のフィールド名・順序・文字列・日付を変えない。クライアント（`Home.tsx` / `CharacterCatalog.tsx` / `GuideHistory.tsx`）と CI（`deploy-pages.yml` の「Verify Railway API」が `build.guideHistory` の `"result"` を grep）が依存する。**唯一の例外は R8**（§4.2 参照）。本計画では「取得済みのデータ構造・データ値はそのまま」で、宣言の移動・派生・重複排除だけを行う。
2. **キャラクターデータのキー規約**。ガイドと推奨PTは**表示名キー**（`GUIDE_OVERRIDES[name]`、`GI_GUIDE_OVERRIDES[name]`、`ZZZ_CHARACTER_GUIDES[name]`、`MANUALLY_CURATED_HIGH_USAGE_CATALOG["game:name"]`、`PARTY_CATALOG["game:name"]`）、凸は **`game:sourceId` キー**（`CURATED["hsr:1310"]` の形。名前キー3件 `genshin:楓原万葉` / `genshin:ベネット` / `genshin:フリーナ` は `constellationProfileFor` の名前フォールバックで生きている）。キー文字列を1文字も変えない（回帰テストと運用スキルのスクリプトが参照する）。
3. **外部スクリプトが参照する公開シンボル**。親リポの運用スキル `hoyoverse-character-audit/scripts/audit-characters.mjs` が `import` する名前を維持する: `CHARACTER_GUIDE_CATALOG` / `HSR_RUNTIME_PATHS` / `ZZZ_RUNTIME_PROFESSIONS`（characterGuideCatalog）、`CHARACTER_GUIDE_METADATA`（characterGuideMetadata）、`characterUpdateLedger`（characterUpdateLedger）、`expectedProfileFor`（expectedGuideProfiles）、`partyRecommendationsFor`（partyRecommendations）、`constellationProfileFor`（characterConstellations）、`ACTIVE_CATALOG_IDENTITIES`（fixtures/identityCatalogSnapshot）、`guideFor`（buildAdvisor）、`generatedHsrGuide` / `generatedGenshinGuide` / `generatedZzzGuide`（individualGuides）、`normalizeGenshinPayload` / `normalizeZzzPayload`（gameProviders）、`BATCH15_CHARACTERS` / `BATCH15_DATE`（batch15Guides）、`batch15ConstellationFor` / `batch15PartyFor`（batch15Constellations / batch15Parties）。追加はよいが、削除・改名・シグネチャ変更をしない。
4. **`variantOf` ガード**（`buildAdvisor.ts:559` `guideFor` の `identity?.variantOf ? undefined : GUIDE_OVERRIDES[name]`）と **`isSafeBatch15Identity`**（`batch15CuratedData.ts:317`）。派生実装（`hsr:1506` 銀狼Lv.999、`hsr:1224` 三月なのか（巡狩）、`hsr:8001`〜`8010` 開拓者）へ基礎キャラクターの個別ガイドを適用しない意図的な挙動（[character-identity-foundation.md](character-identity-foundation.md)）。
5. **`targets: []` は欠落ではなく「比較対象なし」**（[all-character-update-ledger.md](all-character-update-ledger.md) §実装方式の変遷）。数値を補完しない。
6. **第15バッチの上書き経路は本計画では触らない**（`routers.ts` の `applyBatch15CuratedOverrides` / `applyBatch15History`、`characterReference.ts` の `batch15*For` 呼び出し、`server/batch15*.ts`）。畳み込みは挙動不変にできない（§4.3 #3）ため別対応。
7. **キャッシュの時間仕様**: TTL は `ttlFromPayload` の 60秒〜10分クランプ、MiHoMo 主取得は 6秒予算（`MIHOMO_PRIMARY_TIMEOUT_MS`）で Enka へフォールバック、Enka 結果が不完全（`isEnkaResultComplete` false）なら UID キャッシュへ保存しない（Phase 18 設計）。期限切れエントリは `getEntry` が読んだ時に削除する。
8. **ビルド・デプロイの入口**: `package.json` の scripts 名、`server/_core/index.ts` のパス（esbuild の entry）、`dist/index.js`、`/api/health` の JSON（`{"ok":true,"service":"hoyoverse-builder-api"}`）、CORS 既定オリジン、`vite.pages.config.ts` の `base: "/hoyoverse-builder/"`、`railway.toml`、`.github/workflows/*`。すべて変更しない。
9. **MySQL スキーマ・マイグレーション**（`drizzle/`）と `translation_feedback.status` の enum（legacy `reviewed` を含む）を変更しない。
10. **`main` は直接 push 不可**（branch ruleset）。作業は必ずブランチで行い、公開は PR 経由。push・PR 作成はユーザー承認後。
11. **Windows PowerShell では `NODE_ENV=... command` 形式が使えない**。`$env:NAME = "..."` で設定する。依存の再インストールを pnpm が求めても承認しない（`node_modules` は前提コミットで揃っている）。

/**
 * キャラクターデータ API 面のゴールデンスナップショット。
 *
 * 使い方（リポジトリ直下から。TypeScript を直接 import するため tsx 経由で実行する）:
 *   corepack pnpm exec tsx scripts/golden-snapshot.mjs snapshot            # tmp/golden/baseline.json を書き出す
 *   corepack pnpm exec tsx scripts/golden-snapshot.mjs compare             # 現在値と baseline を比較（差分があれば exit 1）
 *   corepack pnpm exec tsx scripts/golden-snapshot.mjs compare --refresh catalogConstellations,referenceConstellations
 *                                                                          # 指定セクションだけ比較を省略し、比較後に baseline を更新する
 *   corepack pnpm exec tsx scripts/golden-snapshot.mjs check-r8            # 図鑑の凸が UID照会経路と一致するかを検査（R8 の受入判定）
 *
 * 目的: リファクタリング前後で公開 API が返すキャラクターデータ（台帳・履歴・図鑑・推奨PT・凸・
 * メタデータ・ガイド）が 1 バイトも変わっていないことを機械的に確認する。外部ネットワークは使わない。
 * このファイルは import されても副作用を持たない（CLI は main() に閉じ、直接実行時だけ動く）。

import { existsSync, mkdirSync, readFileSync, writeFileSync } from "node:fs";
import { dirname, resolve } from "node:path";
import { pathToFileURL } from "node:url";

const GAMES = ["hsr", "genshin", "zzz"];
const load = (relative) => import(pathToFileURL(resolve(relative)).href);
const stable = (value) => JSON.stringify(value);

/** 同名複数IDは「派生ID（"-" 付き）を除いた最初の出現」を採用し、基礎実装の採用IDだけ明示で上書きする。 */
const CATALOG_SOURCE_ID_TIEBREAK = { "hsr:三月なのか": "1001", "genshin:旅人": "10000005", "genshin:イネファ": "10000116" };

function sourceIdIndex(identities) {
  const index = new Map();
  for (const entry of identities.ACTIVE_CATALOG_IDENTITIES) {
    if (String(entry.sourceId).includes("-")) continue;
    const key = `${entry.game}:${entry.providerName}`;
    if (!index.has(key)) index.set(key, String(entry.sourceId));
  }
  for (const [key, sourceId] of Object.entries(CATALOG_SOURCE_ID_TIEBREAK)) index.set(key, sourceId);
  return index;
}

const identityFrom = (index, game, name) => {
  const sourceId = index.get(`${game}:${name}`) ?? name;
  return { game, sourceId, key: `${game}:${sourceId}`, displayName: name, variantOf: null, resolved: true, resolution: "provider" };
};

export async function collect() {
  const [catalog, ledgerModule, historyModule, referenceModule, partyModule, constellationModule, identities, metadataModule, profilesModule, buildAdvisor, providers, batch15History] = await Promise.all([
    load("server/characterGuideCatalog.ts"),
    load("server/characterUpdateLedger.ts"),
    load("server/guideUpdateHistory.ts"),
    load("server/characterReference.ts"),
    load("server/partyRecommendations.ts"),
    load("server/characterConstellations.ts"),
    load("server/fixtures/identityCatalogSnapshot.ts"),
    load("server/characterGuideMetadata.ts"),
    load("server/expectedGuideProfiles.ts"),
    load("server/buildAdvisor.ts"),
    load("server/gameProviders.ts"),
    load("server/batch15History.ts").catch(() => null),
  ]);
  const { CHARACTER_GUIDE_CATALOG, HSR_RUNTIME_PATHS, ZZZ_RUNTIME_PROFESSIONS } = catalog;
  const names = GAMES.flatMap((game) => CHARACTER_GUIDE_CATALOG[game].map((name) => ({ game, name, key: `${game}:${name}` })));
  const index = sourceIdIndex(identities);
  const byKey = (fn) => Object.fromEntries(names.map((entry) => [entry.key, fn(entry)]));
  const references = byKey((entry) => referenceModule.characterReferenceFor(entry.game, entry.name));

  const history = historyModule.guideUpdateHistory();
  return {
    ledger: ledgerModule.characterUpdateLedger(),
    history: batch15History ? batch15History.applyBatch15History(history) : history,
    referenceCatalog: referenceModule.characterReferenceCatalog(),
    // 図鑑応答は「凸以外」と「凸」に分けて保持する。R8 で許可する差分は referenceConstellations だけで、
    // referenceCore（guide / partyRecommendations / status / batch）は R8 でも一致必須にする。
    referenceCore: Object.fromEntries(Object.entries(references).map(([key, value]) => {
      if (value === null || value === undefined) return [key, null];
      const { constellations, ...rest } = value;
      return [key, rest];
    })),
    referenceConstellations: Object.fromEntries(Object.entries(references).map(([key, value]) => [key, value?.constellations ?? null])),
    parties: byKey((entry) => partyModule.partyRecommendationsFor(entry.game, entry.name)),
    idConstellations: byKey((entry) => [0, 6].map((rank) => constellationModule.constellationProfileFor(identityFrom(index, entry.game, entry.name), rank))),
    catalogConstellations: byKey((entry) => [0, 6].map((rank) => constellationModule.constellationProfileForCatalogName(entry.game, entry.name, rank))),
    metadata: metadataModule.CHARACTER_GUIDE_METADATA,
    expectedProfiles: byKey((entry) => profilesModule.expectedProfileFor(entry.game, entry.name)),
    guides: byKey((entry) => entry.game === "hsr"
      ? buildAdvisor.guideFor(entry.name, HSR_RUNTIME_PATHS[entry.name] ?? "")
      : entry.game === "genshin"
        ? providers.genshinGuide(entry.name)
        : providers.zzzGuide(entry.name, ZZZ_RUNTIME_PROFESSIONS[entry.name] ?? "Attack")),
  };
}

/**
 * R8 の受入判定。図鑑（characterReferenceFor）が返す凸が、UID照会経路と同じ解決結果
 * （第15バッチ上書きがあればそれを優先）と一致するかを全248名で検査する。
 */
export async function checkR8() {
  const [catalog, referenceModule, constellationModule, identities, batch15Constellations] = await Promise.all([
    load("server/characterGuideCatalog.ts"),
    load("server/characterReference.ts"),
    load("server/characterConstellations.ts"),
    load("server/fixtures/identityCatalogSnapshot.ts"),
    load("server/batch15Constellations.ts").catch(() => null),
  ]);
  const index = sourceIdIndex(identities);
  const mismatches = [];
  const notCurated = [];
  const unresolvedNames = [];
  let total = 0;
  for (const game of GAMES) {
    for (const name of catalog.CHARACTER_GUIDE_CATALOG[game]) {
      total += 1;
      const key = `${game}:${name}`;
      if (!index.has(key)) unresolvedNames.push(key);
      const actual = referenceModule.characterReferenceFor(game, name)?.constellations ?? null;
      const expected = (batch15Constellations?.batch15ConstellationFor(game, name, 0) ?? null)
        ?? constellationModule.constellationProfileFor(identityFrom(index, game, name), 0);
      if (stable(actual) !== stable(expected)) mismatches.push(key);
      if (actual?.dataStatus !== "curated") notCurated.push(key);
    }
  }
  return { total, mismatches, notCurated, unresolvedNames };
}

async function main() {
  const args = process.argv.slice(2);
  const mode = args[0];
  const opt = (name) => {
    const at = args.indexOf(`--${name}`);
    return at >= 0 ? args[at + 1] : undefined;
  };
  const baselinePath = resolve(opt("out") ?? "tmp/golden/baseline.json");
  const refresh = new Set((opt("refresh") ?? "").split(",").filter(Boolean));

  if (mode === "snapshot") {
    const sections = await collect();
    mkdirSync(dirname(baselinePath), { recursive: true });
    writeFileSync(baselinePath, JSON.stringify(sections), "utf8");
    console.log(`snapshot: ${baselinePath} (${Object.keys(sections).join(", ")})`);
    return;
  }

  if (mode === "check-r8") {
    const report = await checkR8();
    const reportPath = resolve(opt("report") ?? "tmp/golden/r8-check.json");
    mkdirSync(dirname(reportPath), { recursive: true });
    writeFileSync(reportPath, JSON.stringify(report, null, 2), "utf8");
    console.log(`check-r8: total ${report.total} / catalog-id mismatch ${report.mismatches.length} / not curated ${report.notCurated.length} / name unresolved ${report.unresolvedNames.length}`);
    console.log(`mismatch(head): ${report.mismatches.slice(0, 10).join(", ") || "(none)"}`);
    console.log(`not curated: ${report.notCurated.length <= 10 ? report.notCurated.join(", ") || "(none)" : `${report.notCurated.slice(0, 10).join(", ")} ほか`}`);
    console.log(`report: ${reportPath}`);
    process.exit(report.mismatches.length === 0 ? 0 : 1);
  }

  if (mode !== "compare") {
    console.error("usage: golden-snapshot.mjs <snapshot|compare|check-r8> [--out <path>] [--refresh <section,...>] [--report <path>]");
    process.exit(2);
  }

  if (!existsSync(baselinePath)) {
    console.error(`baseline が無い: ${baselinePath}（先に snapshot を実行する）`);
    process.exit(2);
  }
  const baseline = JSON.parse(readFileSync(baselinePath, "utf8"));
  const current = await collect();
  const failures = [];
  for (const section of Object.keys(current)) {
    if (refresh.has(section)) {
      console.log(`skip (refresh): ${section}`);
      continue;
    }
    if (!(section in baseline)) {
      failures.push(`${section}: baseline に無い`);
      continue;
    }
    if (stable(current[section]) === stable(baseline[section])) {
      console.log(`ok: ${section}`);
      continue;
    }
    const detail = [];
    if (current[section] && typeof current[section] === "object" && !Array.isArray(current[section])) {
      for (const key of new Set([...Object.keys(current[section]), ...Object.keys(baseline[section] ?? {})])) {
        if (stable(current[section][key]) !== stable(baseline[section]?.[key])) detail.push(key);
      }
    }
    failures.push(`${section}: 差分あり${detail.length ? `（${detail.length}件: ${detail.slice(0, 8).join(", ")}${detail.length > 8 ? " ほか" : ""}）` : ""}`);
  }
  if (failures.length > 0) {
    // 差分がある場合は baseline を書き換えずに終了する（許可していない差分を承認しないため）。
    console.error(failures.map((line) => `NG ${line}`).join("\n"));
    process.exit(1);
  }
  if (refresh.size > 0) {
    for (const section of refresh) baseline[section] = current[section];
    writeFileSync(baselinePath, JSON.stringify(baseline), "utf8");
    console.log(`refreshed: ${[...refresh].join(", ")}`);
  }
  console.log("golden compare: all sections equal");
}

const invokedDirectly = process.argv[1] !== undefined && pathToFileURL(resolve(process.argv[1])).href === import.meta.url;
if (invokedDirectly) await main();
