## 表示3案

1. 超撃破・耐久あり: ホタル / ダリア / 帰忘の流離人 / 霊砂。非撃破時の超撃破、擬靭性、炎削靭と回復を組む。
2. 超撃破・耐久なし: ホタル / ダリア / 帰忘の流離人 / ルアン・メェイ。敵の攻撃を削靭と遅延で抑えられる場合に限定。長期戦・高被ダメージでは第1案。
3. 超撃破・代替支援: ホタル / ルアン・メェイ / 開拓者（調和） / ギャラガー。ダリア・流離人なしの場合の案。入手性を一律にF2Pと断定しない。

無条件の最適順位ではなく、耐久を備えた基本案を先頭にする。三言語で役割・条件を記録。新規 `targetChanges` は空。ダリア・ルアン等の戦闘中速度補正を公開現在値へ足さず、旧PTの150/154等の補正を新案へ流用しない。基本ガイドの数値再精査は対象外。
