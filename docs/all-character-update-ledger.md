# 全キャラクター個別更新台帳

この台帳は、HSR・原神・ZZZのカタログ対象キャラクターを、ロール共通値ではなく**キャラクターごとの公開プロフィール比較**へ更新する進捗を示す。対象一覧は [`server/characterGuideCatalog.ts`](../server/characterGuideCatalog.ts) を唯一の母集団とし、画面の更新履歴にも同じ集計を表示する。

集計の正本は [`server/characterUpdateLedger.ts`](../server/characterUpdateLedger.ts)。本ファイルはその要約であり、値が食い違う場合はコード側を正とする。

> 同期状況: 2026-09-13 に第19バッチ（ZZZ クラレッタのカタログ追加）へ合わせて再同期した。2026-09-11 に第18バッチ（HSR 3名のカタログ追加）へ合わせて再同期した。2026-09-08 に第17バッチの実施へ合わせて再同期した。第3〜15バッチの内容はコードの `REVIEWED_BATCHES` から復元した要約であり、過去の公開コミットや当時の検証記録までは復元していない。

## 実装方式の変遷

- 第1〜14バッチ: 基底データ（`buildAdvisor.ts` / `gameProviders.ts` / `characterConstellations.ts` / `partyRecommendations.ts`）を直接更新。
- 第15バッチ: API境界（`routers.ts`）と図鑑（`characterReference.ts`）で個別に上書きする構成。
- 第16バッチ: 基底データの直接更新へ戻し、UID照会と図鑑（UID不要）の双方へ同じ値が届くようにした。図鑑はカタログ名しか持たないため、`constellationProfileForCatalogName()` で確認済み source ID へ解決してから凸を引く。
- 第19バッチ: 母集団へ ZZZ 1名を追加（251→252名）。新特性「鋭御」のコード側対応は先行する Phase B で実施済み。心象映画の日本語名は2出典で割れたため、英語版の出典で裏を取って採用した。出典が割れた会心ダメージは目標に登録しない。
- 第18バッチ: 母集団へ HSR 3名を追加（248→251名）。星魂本文は StarRailRes の公式ゲームデータ（日本語・英語・中国語）から取得。未実装・取得元にIDが無いキャラクターは追加しない（保留は根拠メモ参照）。
- 第17バッチ: 残り28名を一括更新し、通常27名と旅人7元素の全204凸効果を生成データとして基底経路へ登録。固定目標値のない `targets: []` は「比較対象なし」として表示する。

## 1バッチの必須完了条件

各キャラクターは、以下を**すべて**満たした後に分割公開する。

1. 最新の公式実装情報と更新日付き個別ビルド・PTガイドを照合し、根拠URLと確認日を研究メモへ記録する。
2. 公開プロフィールで比較する個別目標、主ステータス、条件注記を更新する。戦闘中、編成依存、凸依存の数値は現在値へ混ぜない。
3. 全6段階の星魂・命ノ星座・心象映画を確認し、公開値の目標側へ適用できる数値だけを明示的に登録する。
4. 最大3案の推奨PTを個別根拠へ更新し、役割、シナジー、バージョン、日付、根拠、公開値に影響する条件を記録する。
5. 型検査・全回帰テスト・該当する公開UID画面確認・更新履歴を完了する。

公開前に未確認の効果や数値を補完・推測しない。根拠が不足する場合は、そのキャラクターを「データ収集中」として残し、別キャラクターでバッチ数を補う。
