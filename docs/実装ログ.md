### Phase 19: MiHoMo正規化経路の「現在のステータス」欄ラベル重複を修正 — 完了

- 完了日: 2026-09-08
- 実装した内容:
  - Phase 18の残課題（MiHoMo経路で同一ステータス名が絶対値・割合値の両方で重複表示される既存の表示上の粗さ）を調査・修正した。
  - `server/buildAdvisor.ts` の `parseCharacter` は MiHoMo `sr_info_parsed` の `properties[].name` をそのまま `allStats[].name` へ使っていた。StarRailRes `index_new/jp/properties.json`（MiHoMoが参照する本家データ）を直接確認したところ、`AttackAddedRatio`/`AttackDelta` はいずれも `name: "攻撃力"`、`HPAddedRatio`/`HPDelta` はいずれも `name: "HP"` で、`field` も `atk`/`hp` と同一、区別できるのは `percent` フラグのみだった（推測ではなく実データで確認）。このため割合ステータスと絶対値ステータスがUI上で同じラベルの行として重複表示されていた。

  - `server/buildAdvisor.test.ts` に実データ相当（`name` 重複あり）の回帰テストを追加。修正前は重複行、修正後は「HP」/「HP%」・「攻撃力」/「攻撃力%」に分離されること、単独の割合ステータス（会心率）には不要な `%` が付かないことを検証した。
